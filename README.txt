САЙТ «МИМАСТЕР» — ИНСТРУКЦИЯ

Состав:
- index.html — главная страница: процесс работы с прошивками Xiaomi.
- prices.html — прайс-лист услуг.
- experience.html — информация об опыте и демонстрационные отзывы.
- register.html — форма регистрации.
- css/style.css — оформление и адаптивная верстка.
- js/register.js — проверка формы регистрации на стороне браузера.

Как открыть:
1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте файл index.html в современном браузере.
3. Для перехода между разделами используйте меню сайта.

Регистрация:
- Имя пользователя: 3–20 символов; латинские буквы, цифры и знак подчёркивания.
- Первый символ имени пользователя должен быть латинской буквой.
- Пароль: минимум 8 символов.
- Пароль нужно повторить для проверки.
- Требуется подтвердить, что форма демонстрационная.

ВАЖНО:
Это статический демонстрационный сайт. Форма проверяет поля в браузере, но не создаёт аккаунт, не хранит пользователей и не отправляет данные на сервер. Для настоящей регистрации необходим сервер, база данных, безопасное хеширование паролей, HTTPS, защита от злоупотреблений и политика обработки персональных данных.

Цены на странице приведены как пример макета и должны быть заменены на реальные. Отзывы на странице опыта — демонстрационные примеры, не реальные рекомендации; замените их настоящими отзывами с разрешения клиентов.
